  1. Question 1
    Find the first partial derivatives of the given function.

    • `z=xe^(5y)`

    • `f(m,n)=m ln(m+n^2)`
    • `f(x,y,z)=xy^2z^3+2yz`
  2. Question 2
    Find the first partial derivative of the given function and evaluate it as indicated:
    • `f(x,y)=sqrt(x^2+y^2)`; find `f_x(5,12)`
    • `f(x,y)=cos(x-2y)`; find `f_y(pi, pi/4)`

  3. Question 3
    Find `(del z)/(del x)` and `(del z)/(del y)` using implicit differentiation: `sin(xyz)=x+3y+2z`.
  4. Question 4
    Find the four second partials of `f(x,y)=x^3y^2-2xy^4`.
  5. Question 5
