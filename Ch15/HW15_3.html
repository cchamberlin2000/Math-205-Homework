Homework Section 15.3

  1. Question 1
    Evaluate the following iterated integrals.
    • `int_1^2 int_y^2 8xy dx dy`
    • `int_0^(pi/3) int_0^(sin theta) cos theta dr d theta`
  2. Question 2
    Evaluate the following double integrals.
    • `int int_R y/(x^3+1) dA`, `R={(x, y) | 1 <= x <= 4, 0 <= y <= 2x}`
    • `int int_R e^(y//x) \ dA`, `R={(x,y) | 0 <= y <= x^3, 1 <= x <= 2}`
    • `int int_R x sqrt(y^2-x^2) \ dA`, `R={(x,y) | 0 <= x <= y, 0 <= y <= 1}`
    • `int int_R x sin y \ dA`, `R` is bounded by `y=0`, `y=x^2`, `x=1`
  3. Question 3
    Find the volume of the solid regions described below.
    • Below the plane `z=2x+y` and above the region bounded by `y=x` and `y=x^2`.
    • Below the surface `z=2xy` and above the triangle with vertices (1, 1), (3, 1), and (3,5).
    • Bounded by the cylinder `x^2+z^2=9` and the planes `3y=x`, `x=0`, `z=0` in the first octant.
  4. Question 4
    Evaluate the integrals by reversing the order of integration:
    • `int_0^2 int_x^2 e^(y^2) dy dx`
    • `int_0^2 int_(y^2)^4 y cos(x^2) dx dy`
