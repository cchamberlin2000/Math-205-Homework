  2. Question 2
    Determine whether or not `bb(F)` is a conservative vector field. If it is, find a function `f` such that `bb(F) = nabla f`.

    • `bb(F)(x,y) = (y e^x+cos y) bb(i) + (e^x+x sin y) bb(j)`
  3. Question 3
    Let `C` be a piecewise smooth curve in an open region that goes from the point (2,3) to the point (5,6), and `f(x,y) = x^2y` is a potential function for a continuous vector field `bb(F)(x,y)`. Find the work done by `bb(F)(x,y)` on an object moving along the path from (2,3) to (5,6).
